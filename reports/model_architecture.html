STAGE 03앵커 역산 — 2025를 보는 유일한 창

학습 데이터는 2024년에서 끝나고 평가는 2025년이다. 그런데 test.csv의 asof_* 컬럼에는 그 투수의 2025 시즌 진행분이 이미 녹아 있다. 앵커를 빼면 그게 분리된다.

같은 방식이 7개 지표에 적용된다 — 투수의 성공률·역방향률·가운데율·볼률·스트라이크율, 타자의 성공률·가운데율. 축소 강도를 4종(k = 25 / 75 / 400 / 1000)으로 나눈 *_k* 피처가 따로 있는 이유는, 시즌 초반(표본 얇음)과 후반(표본 두꺼움)에서 신뢰해야 할 정도가 다르기 때문이다. 모델이 상황에 맞는 축소 강도를 스스로 고르게 둔다.

신경망 축의 내부

NN 축은 두 개의 풀을 α로 섞는다. 두 풀은 학습 시점도 목적도 다르다.

기존 풀 8개 — 단독 729.7

TabM 6개 + FT-Transformer 2개. 60여 개 설정을 탐색해 단독 성능이 아니라 트리와의 블렌딩 이득으로 골랐다. 전부 emb=0이라 투수/타자 ID를 아예 쓰지 않는다.

멀티태스크 풀 8개 — 단독 711.3

MTabM: trunk를 공유하고 헤드 5개(y + 성분 4개)를 동시에 학습한다. L3는 보조 손실을 annealing으로 끄고, L5는 emb=8로 ID 임베딩을 켠다. 추론 시엔 헤드 0만 쓴다.

두 풀을 섞는 게 각각보다 낫다

기존 풀 729.7, 멀티태스크 풀 711.3인데 α=0.4로 섞으면 755.0이 된다. 어느 쪽 단독보다도 높다. 멀티태스크 NN이 앙상블에 남아 있는 근거는 정확도가 아니라 이 상보성이다.

STAGE 06블렌드 수식

합산은 전부 로짓 공간에서 일어난다. 확률 평균이 아니라 로짓 가중합인 이유는, 극단 확률에서의 정보를 보존하기 위해서다.

# 축별 로짓
lx = logit(XGB 12시드 확률 평균)
ll = logit(LGB 7시드 확률 평균)
lc = logit(CatBoost 확률)
zn = (1−α)·기존NN 8개 로짓 평균 + α·멀티태스크NN 8개 로짓 평균

# 트리 축 합산 후 (1−wn) 이 되도록 재정규화
tree = wx·lx + wl·ll + wc·lc
tw   = wx + wl + wc
sc   = (1 − wn) / tw

# 최종
p = σ( tree·sc + wn·zn )
p = σ( logit(p) + drift )        # drift = −0.020

# v10a 실제 값
wx=.45  wl=.35  wc=.20  wn=.30  α=0.4
실효 가중  XGB .315 / LGB .245 / CB .140 / NN .300

축이 하나 실패해도 파이프라인이 멈추지 않는다. LightGBM import가 실패하면 wl=0, CatBoost 로드가 실패하면 wc=0으로 두고 tw가 다시 계산된다. 멀티태스크 NN이 실패하면 α=0으로 되돌아가 기존 풀만 쓴다. NN이 전부 실패하면 트리 축만으로 제출한다.

STAGE 07드리프트 보정과 최근성 가중

두 장치 모두 같은 문제를 다룬다 — 학습은 2019–2024, 평가는 2025.

학습 시 · 최근성 가중

시즌 지수감쇠 sample_weight, 반감기 2시즌, 2024 기준. 2024는 1.000, 2023은 0.707, … 2019는 0.177. 대리 실험에서 반감기 2.0이 최적으로 확인됐고, 2024에 가중을 몰아주면 오히려 크게 나빠졌다.

추론 시 · 로짓 시프트

최종 확률에 −0.020을 더한다. 리그 제구율이 .5495 → .4897로 매년 하락하는데 모델은 2024 수준을 예측하기 때문이다. 학습 시즌 추세로만 추정한 상수이며 평가 데이터 분포는 참조하지 않는다.

이 상수는 LB에서 검증됐다

보정 없음(1055.1587)과 −0.035(1054.1189) 두 점으로 실제 편향을 +0.0042로 역산하고, 최적값 −0.020의 점수를 1062.06으로 예측했다. 실제 제출 결과는 1061.9107이었다. 오차 0.15점.

STAGE 09정당화가 약한 부분

팀 논의를 위해, 구조에서 "왜 여기 있는가"에 깨끗한 답이 없는 지점들을 그대로 적는다.

LightGBM은 버려질 뻔했다

튜닝 후 폴드2024에서 블렌드 가중치를 격자 탐색했을 때 최적해는 LGB에 가중치 0을 줬다(XGB .80 / CB .10 / NN .10, BSS 876.4). 네 축을 다 유지한 구성(874.6)과의 차이는 1.8점뿐이라 안전하게 유지 쪽을 택했지만, 이 축의 기여는 확실하지 않다. 다만 v10 실패가 보여주듯 CV 최적해를 믿을 근거도 없다.

멀티태스크 NN도 α=0을 받은 적이 있다

같은 격자 탐색에서 α=0(기존 풀만)이 최적으로 나왔다. 그러나 α=0.4 혼합이 두 풀 단독보다 높다는 별도 측정(755.0 vs 729.7 / 711.3)이 있어 유지 중이다. 두 측정이 상충하며, 아직 LB로 분리 검증되지 않았다.

CatBoost는 단독 성능이 가장 낮다

745.1로 XGB보다 122점 낮다. 깊이를 키우면 d8 639.5, d10 436.7로 붕괴한다. 그럼에도 남아 있는 이유는 v9에서 이 축을 추가했을 때 LB가 +2.78 올랐기 때문이다 — 즉 단독 성능이 아니라 LB 실측이 근거다.

성분 모델만 재튜닝에서 빠져 있다

XGB·LGB·CatBoost는 전부 재탐색했지만 cmp_* 4개는 아직 옛 하이퍼파라미터(d6 · mcw1500 · n600)다. 이 모델들의 출력이 트리 축 전체의 입력으로 들어가는데도 그렇다. 성분 라벨이 y보다 신호가 2배 강하므로 튜닝 여지가 남아 있을 수 있다.

구종 라벨은 알지만 쓸 수 없다

asof_pitcher_pitchmix_n도 같은 방식으로 차분되어 매 투구의 구종(fastball 54.1% / breaking 29.6% / offspeed 16.3%)이 역산된다. 진짜 구종을 피처로 넣으면 폴드2024가 822.8 → 1005.7로 +183 오른다. 그러나 투구 전 정보로 구종을 예측하면 정확도가 54.9%(최빈 52.3%)에 그쳐 합법 경로로는 +1.8뿐이고, 실제 구종은 규칙이 명시적으로 금지한다. 가장 큰 신호 덩어리가 원리적으로 접근 불가라는 뜻이다.
