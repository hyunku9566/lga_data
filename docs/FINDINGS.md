## 3. 부스터별 하이퍼파라미터 방향이 서로 반대다

셋 다 한 번도 재탐색된 적 없이 잘못된 지점에 있었다. 그런데 **최적 방향이 정반대**다.

| 부스터 | 원래 → 최적 | 폴드2024 | 방향 |
|---|---|---|---|
| **XGB** | d6/mcw1500/n600 → d10/mcw6000/n4000/lr.004 | 821.7 → 869.7 (+48.0) | **더 크게 + 더 느리게** |
| **LGB** | leaves31/mcs1500 → leaves15/mcs6000 | 796.3 → 830.8 (+34.5) | **더 작게 + 더 규제** |
| **CatBoost** | d6/n2000/lr.03 (변경 없음) | 745.1 | **현재가 최적.** d8 639.5, d10 436.7로 붕괴 |

XGB는 레벨 단위 성장이라 depth를 키워도 균형을 유지하지만, LGB는 리프 단위라 leaf가 늘면 한쪽으로 깊게 파고들어 이 저신호 데이터에서 즉시 과적합한다. CatBoost는 고카디널리티 `pitcher_id` 에 대한 ordered target statistics가 깊이에 매우 민감하다.

**교훈: 한 부스터의 튜닝 결과를 다른 부스터에 옮기지 마라.**

## 4. 정보 함량 — 어느 컬럼에 신호가 있나

모델 없이 직접 측정. 그룹별 제구율 분산에서 표본 노이즈를 보정한 BSS 상한
(`Var_true ≈ Var_obs − Σw·p(1−p)/n`).

| 컬럼군 | BSS 상한 |
|---|---|
| **투수 ID** | **797** |
| 투수 커리어 제구율 (20분위) | 607 |
| 구종 (역산) | 212 |
| 시즌 | 147 |
| 타자 ID | 121 |
| 볼카운트 (12셀) | 31 |
| 이닝 | 25 |
| LI (상황 중요도) | 22 |
| 주자 상황 | 3.9 |

**신호가 투수 정체성에 몰려 있다.** 볼카운트 전체 폭이 3.9%p(0B1S .5265 → 3B2S .4873)인데 구종 하나가 5.5%p를 만든다.

이 표가 2절의 실패들을 사후 설명한다 — 성분×상황(−11.4), 콜드스타트(−1.5) 등 **상황 쪽을 판 시도가 전부 실패한 건 거기에 신호가 없어서**다.

**미해결 단서**: 투수 ID(797)와 커리어 제구율(607)의 격차 **190**. 투수마다 "제구율 하나"로 요약되지 않는 고유 정보가 남아있다는 뜻일 수 있으나, 20분위 이산화 손실이 섞여 있어 **얼마가 실신호인지 미측정**.

> **이 수치를 오해하지 마라.** 무작위 분할은 같은 경기·같은 타석의 연속 투구가 학습/검증 양쪽에 들어가는 **누수**가 있다. 1146이 달성 가능하다는 뜻이 아니다. **격차 중 순수 누수분이 얼마인지는 미측정.**

그래도 방향은 가리킨다 — 손실은 "정보가 없다"가 아니라 **"올해 선수 상태를 모른 채 다음 해를 예측한다"** 에서 난다.

## 7. ABS regime — 확증되지 않은 가설

2024 시즌부터 데이터 거동이 다르다. 원인으로 ABS(자동 볼판정) 도입이 지목됐고, 이를 근거로 검증 기준을 폴드2024 단독으로 바꿨더니 숨어있던 HPO 이득이 드러났다(평균 기준 +15 → 폴드2024 기준 +41.5).

**그런데 월별 데이터에 시즌 시작 단절이 없다:**

```
2023  4월 .4858  5월 .5006  6월 .5060 ... 10월 .5100
2024  3월 .5038  4월 .4959  5월 .4916 ...  9월 .4749
```

계단형 regime 변화라면 2024년 3~4월부터 확 낮아야 하는데, 오히려 2023년 4월(.4858)보다 2024년 3월(.5038)이 높다. 2024는 시즌 내내 완만히 하강한다.

**"2024부터 다르다"는 실측이지만 "원인이 ABS"는 미확증.** 원인이 무엇이든 폴드2024를 주 검증으로 쓰는 실무적 판단 자체는 유효하다.

### 미측정 — 해볼 가치 있음
1. **성분 모델 재튜닝** — `cmp_reverse/middle/ball/strike` 4개만 아직 d6/mcw1500/n600이다. 이 출력이 트리 축 전체의 입력인데도 재튜닝에서 빠졌다. 성분 라벨은 자체 스킬이 y보다 2배 강하다 (reverse 1431 / ball 1778 / strike 1211 / middle 887 vs y 809). 코드는 `experiments/run29_cmp_retune.py` 에 준비돼 있다.
2. **설정 다양성 앙상블** — 같은 설정 시드 12개 대신 성능이 비슷한 서로 다른 설정 4개(n4000/n2000/lossguide512/d12)를 섞는 게 나은지. 코드는 `experiments/run30_configdiv.py`.
3. **투수 표현 개선** — 4절의 격차 190이 실신호인지 이산화 손실인지 가르기.
4. **NN 축 재튜닝** — 기존 NN들은 트리가 810이던 시절에 선택됐다. 지금 트리는 870이고 NN 축 단독은 755.0이다.
