# 앙상블 구조

기준 모델은 **v10a** (LB 최고 1068.5958). 실물은 `submit_v10/` 이며 `consts.json` 이 v10a 가중치로 맞춰져 있다.

> 다이어그램이 포함된 버전: [`reports/model_architecture.html`](../reports/model_architecture.html)

## 전체 파이프라인

```
test.csv (2025, 48컬럼)
   │
   ├─ featurize() ─────────────────► 114 base 피처
   │     원본 통과 37 + 범주 인코딩 + 앵커 역산 + 투수x상황 + 매치업
   │     + 트랙맨 프로파일 8 + 다중축소 8
   │
   ├─ 성분 모델 4개 (cmp_*) ──────► 성분 로짓 4 + 파생 2 = 6
   │     입력: base 114 / 출력: reverse·middle·ball·strike 로짓
   │
   └─ 합계 120 피처
         │
         ├─ XGB x12  ─┐
         ├─ LGB x7    ├─ 트리 축 (가중합)
         ├─ CatBoost  ─┘
         └─ NN x16    ─── 신경망 축 (기존 8 + 멀티태스크 8, α 혼합)
               │
         블렌드 → 드리프트 보정 (-0.020) → submission.csv
```

## 구성원별 입력·출력·역할

| 구성원 | 개수 | 입력 | 출력 | 단독 BSS (폴드2024) | 실효 가중 |
|---|---|---|---|---|---|
| **성분 모델** `cmp_*` | 4 | base 114 | 성분 로짓 → **트리 축의 입력 피처** | 자체 887~1778 | — |
| **XGB** | 12 | 120 | 확률 → 로짓 | 867.7 | .315 |
| **LightGBM** | 7 | 120 | 확률 → 로짓 | 830.8 | .245 |
| **CatBoost** | 1 | 120 (범주 9개는 문자열) | 확률 → 로짓 | 745.1 | .140 |
| **NN (기존 풀)** | 8 | 98 수치 + 범주 | 로짓 | 729.7 | .300 |
| **NN (멀티태스크)** | 8 | 105 수치 + 범주 2 | 로짓 (헤드 0만 사용) | 711.3 | (위에 포함) |

총 **25개 모델** + 성분 모델 4개.

### 성분 모델 — 숨어 있던 라벨을 쓰는 통로
`asof_*` 차분으로 복원한 `reverse`/`middle`/`ball`/`strike` 를 **보조 타깃**으로 학습한다. 추론 시 이 4개 모델이 합법 피처만 보고 성분 확률을 예측하고, 그 로짓이 y 모델의 피처가 된다.

파생 2개:
```
cmp_bad  = cmp_reverse + cmp_middle     (y=1 이려면 둘 다 0이어야 함)
cmp_zone = cmp_strike  - cmp_ball
```

타깃 구조가 `y = ¬reverse ∧ ¬middle ∧ Z` 이므로 `cmp_bad` 는 직접적으로 실패 요인을 표현한다.

**성분 라벨의 자체 스킬** (같은 114피처·같은 XGB):
```
ball 1778 > reverse 1431 > strike 1211 > middle 887 >  y 809
```
y보다 신호가 2배 강하다. 이래서 스태킹이 통했다 (+9.3).

### 신경망 축 — 두 풀의 상보성
```
기존 NN 풀 (TabM/FTT, v4_nn_sel.json)   729.7
멀티태스크 NN 풀 (MTabM, 헤드 5개)         711.3
α=0.4 혼합                              755.0  ← 각각보다 높다
```

멀티태스크 NN(`MTabM`)은 trunk를 공유하고 헤드가 5개(y + 성분 4)다. 학습 시 `loss = Brier(y) + λ·mean_c Brier(c)` 로 보조 라벨이 표현을 함께 깎고, **추론 시엔 헤드 0(y)만 쓴다.**

채택된 두 원형:
- **L3**: λ=1.0 → 0 annealing (초반엔 성분으로 표현을 깎고 후반엔 y로 수렴). 폴드2024 블렌딩 이득 +11.6
- **L5**: λ=1.0 고정 + `pitcher_id`/`batter_id` 임베딩 8차원. +6.9

단일태스크 대조군(L0)은 +1.3 이었다. **멀티태스크 순효과 +10.3.**

## 앵커 역산 — 2025를 보는 유일한 창

학습에 2025 데이터가 없는데도 **2025 시즌 진행분**을 볼 수 있는 이유다.

`asof_pitcher_n` 은 커리어 누적 투구수, `asof_pitcher_success_rate` 는 커리어 누적 성공률이다. 곱하면 누적 성공 횟수가 된다.

```
앵커 테이블: 각 투수의 2024 시즌 종료 시점 (a_n, a_succ)   ← train.csv 에서 생성

테스트 행에서:
  dn = asof_pitcher_n - a_n                      = 2025 시즌 진행 투구수
  ds = asof_n x asof_rate - a_succ               = 2025 시즌 진행 성공수

  p_succ_ssn = (ds + K x 리그평균) / (dn + K)      K=150
  p_succ_k{25,75,400,1000}                       축소 강도 4단계
```

**이 트릭 덕분에 "이 투수가 2025년에 지금까지 어떻게 하고 있는가"가 행 단위로 복원된다.** 다른 테스트 행을 전혀 참조하지 않으므로 규칙에도 어긋나지 않는다.

같은 방식으로 `p_rev_ssn`, `p_mid_ssn`, `p_ball_ssn`, `p_stk_ssn`, `b_succ_ssn` 등이 만들어진다.

## 블렌드 수식

```python
tree = wx*logit(p_xgb) + wl*logit(p_lgb) + wc*logit(p_cb)
tw   = wx + wl + wc
sc   = (1 - wn) / tw

zn   = (1-alpha) * mean(기존NN 로짓) + alpha * mean(멀티태스크NN 로짓)

p    = sigmoid(tree * sc + wn * zn)
p    = sigmoid(logit(p) + drift)          # drift = -0.020
```

**v10a 가중치**: `wx=.45, wl=.35, wc=.20, wn=.30, alpha=0.4`
→ 실효 **XGB .315 / LGB .245 / CB .140 / NN .300**

각 축은 실패 시 자동으로 0이 되고 나머지가 재정규화된다 (LGB 로드 실패, CatBoost 예외, NN 시간초과 등).

## 정당화가 약한 부분

문서화하면서 드러난 것들이다. 숨기지 않고 적는다.

### LightGBM은 버려질 뻔했다
폴드2024 격자탐색의 최적해는 **LGB 가중치 0** 이었다 (876.4). 전체를 유지한 균형 배분과 차이는 1.8점. 그런데 그 최적해를 실제로 제출했다가 **LB −11.66** 을 맞았다. 지금은 다양성 유지 쪽에 서 있지만, **CV 근거는 없고 LB 실측 한 점이 근거의 전부**다.

### 멀티태스크 NN도 α=0을 받은 적이 있다
같은 격자탐색에서 α=0(멀티태스크 버리기)이 최적으로 나왔다. 그런데 별도로 재보니 α=0.4 혼합(755.0)이 각 풀 단독(729.7 / 711.3)보다 높다. **두 측정이 상충한다.** 트리 축이 강해진 상태에서 NN 축 전체 비중을 줄이다 보니 내부 구성 판단까지 왜곡된 것으로 보인다.

`results31` 의 두 폴드 동시 개선 탐색에서는 상위 후보들이 공통으로 **α=0.7** 을 가리킨다 — 현재 0.4보다 훨씬 높다. **미검증.**

### CatBoost는 단독 성능이 가장 낮다
745.1로 네 축 중 최하위다. 근거는 **LB 실측 +2.78** 하나뿐이다. 다양성 기여로 보고 유지 중이다.

### 성분 모델만 재튜닝에서 빠져 있다
XGB(+48.0), LGB(+34.5)를 재튜닝했지만 `cmp_*` 4개는 여전히 **d6/mcw1500/n600/lr0.008** 이다. 이 출력이 트리 축 **전체의 입력**인데도 그렇다. 코드는 준비돼 있으나(`experiments/run29_cmp_retune.py`) 아직 실행 전.

### 구종 라벨은 알지만 쓸 수 없다
구종을 알면 +182.9. 예측하면 +1.8. 규칙이 금지한다. **앙상블에서 가장 큰 미개척 신호이며 앞으로도 개척 불가.**
