## 3. 근본 원인 (파이프라인 단계별)

### 3-1. [치명적] 조기중단 신호가 누수돼 있다

모든 NN 스크립트가 동일하다 — `run_nn_pure.py:120`, `run_ftt_clean.py:146`:
```python
rng.shuffle(idx_tr)                 # 학습 인덱스를 무작위로 섞고
n_hold = int(len(idx_tr)*0.06)      # 6% 를 홀드아웃으로
idx_hold = idx_tr[:n_hold]
```
**무작위 분할이다.** 실제 과제는 시간 분할인데.

측정한 누수량:
```
랜덤 6% 홀드아웃 66,976행 중 '같은 경기'가 학습셋에도 있는 비율 : 0.9999
                              같은 투수가 학습셋에 있는 비율      : 1.0000
```
그리고 우리가 측정한 분산분해에서 **경기(그날 폼)가 잠재분산의 61.9%** 다.

즉 랜덤 홀드아웃은 **잠재분산의 62% 를 학습셋과 공유한다.** 같은 경기의 다른 투구가
학습셋에 있으니 그날 폼을 그냥 외우면 홀드아웃 손실이 내려간다.
시간분할 검증에는 그 정보가 **존재하지 않는다.**

`FINDINGS.md` 6절이 같은 것을 이미 쟀다: **무작위 80/20 1146.4 vs 시간분할 818.9 (+327.5).**

**결과**: 조기중단이 엉뚱한 지점에서 발화한다. `results_ftt_clean/log.txt` 를 보면
홀드아웃 손실이 0.79319 -> 0.79160 으로 거의 안 움직이며 "★ 최저손실" 을 계속 갱신하는데,
그동안 실제 폴드 성능은 무너지고 있다. **모델 선택 신호 자체가 고장나 있다.**

반면 트리는 조기중단을 **안 쓴다**. `n_estimators=2000` 고정 + 강한 규제다.
누수된 신호를 소비할 통로가 없다.

### 3-2. 규제의 '단위' 가 다르다

이 데이터는 **Brier skill 1%** 다. y 분산 0.25, 잠재분산 0.00627 -> **SNR 약 1:40**.

트리 규제는 **표본 수 단위**다:
```
XGB  min_child_weight=6000, max_depth=10
LGB  min_child_samples=6000, num_leaves=15, extra_trees
CB   depth=4  (리프 16개)
```
`min_child_weight=6000` 은 **모든 예측이 최소 6000행의 평균**이라는 하드 제약이다.
리프당 추정잡음 sd = sqrt(0.25/6000) = **0.0065**, 투수 신호 sd = **0.046**.
즉 구조적으로 **SNR 7:1 을 보장**한다.

NN 규제는 **파라미터 공간**이다 (`drop=0.1`, weight decay).
"몇 개 행으로 예측하지 마라" 를 표현할 방법이 없다. 배치 8192 안에서
개별 행이 그래디언트를 그대로 밀어넣는다. 1% 신호에서 이건 잡음 적분이다.

### 3-3. NN 이 잘하는 일이 여기 남아있지 않다

NN 의 강점은 **표현/상호작용 학습**이다. 그런데 잔차 감사(폴드2024) 결과:

| 축 | 잔차 상한 |
|---|---|
| 투수 x 볼카운트 | **0.0** |
| 볼카운트 | 8.7 |
| 이닝 | 1.0 |
| 아웃 | 0.3 |
| 주자 | 3.6 |

**상호작용이 이미 다 짜여 있다.** 124피처는 이미 충분통계량(수축된 비율 + 표본수)이라
남은 함수는 거의 단조·가법이다. 그건 트리가 제일 잘하는 형태고, NN 이 이길 여지가 없다.

### 3-4. 고카디널리티 임베딩이 잡음을 외운다

`pitcher_id` 792 / `batter_id` 830, `emb=32` -> 약 5.1만 파라미터.
1% 신호에서 투수당 1,862구로 32차원 임베딩을 학습하면 잡음을 적합한다.

CatBoost 는 ordered target statistics 로 누수 방지가 **알고리즘에 내장**돼 있다.
`results19/log.txt`: CB 범주네이티브가 축에 얹은 이득 **+7.4** (수치만 버전은 +4.0).

### 3-5. 타깃이 베르누이 p≈0.5 다

`y = ¬reverse ∧ ¬middle ∧ Z` 로 확정되는 이진값이라 환원불가 분산이 0.25 로 지배적이다.
BCE 그래디언트는 사실상 잡음이다. 트리는 **분할 전에 6000행을 평균**내지만
SGD 는 평균 없이 매 스텝 파라미터를 민다.

## 4. 고칠 수 있는 것 / 없는 것

### 고칠 수 있다 — 조기중단 홀드아웃을 시간분할로
```python
# 지금 (누수)
rng.shuffle(idx_tr); idx_hold = idx_tr[:n_hold]

# 고친 것 — 학습창의 '마지막 시기' 를 홀드아웃으로
ord_ = np.lexsort((RAW.game_month.values[idx_tr], season[idx_tr]))
idx_hold = idx_tr[ord_][-n_hold:]      # 시간상 뒤쪽
idx_train = idx_tr[ord_][:-n_hold]
```
이러면 조기중단이 epoch 1~2 의 진짜 최고점에서 발화한다.
지금은 그 지점을 지나 붕괴할 때까지 학습한다.

**단, 이건 '제대로 측정' 되게 만드는 것이지 '이기게' 만드는 것이 아니다.**
누수를 걷어내도 DL 최고치는 776.9(폴드2024)로 XGB 872.9 보다 **96점 아래**다.
그 격차의 원인은 3-2 ~ 3-5 이고 그건 구조적이다.

### 고칠 수 없다 — 구조적 열세
1% 신호 + 상호작용 없음 + 고카디널리티 범주 + 베르누이 타깃.
이 네 조건이 겹치면 **표본수 단위 규제를 가진 앙상블 트리가 원리적으로 유리**하다.
이건 이 대회 데이터의 성질이지 구현 문제가 아니다.

### 그래서 DL 의 자리는
**대체가 아니라 다양성 축**이다. 그리고 그 자리는 이미 차 있다 —
NN 축 단독 755, 블렌드 가중 .30. `CURRENT_BEST.md` 실측으로 .30 -> .40 은 **-3.47** 이다.
트리를 빼고 NN 만 남기는 방향은 그 기울기를 더 타고 내려가는 것이다.
