## 우리 코드는 이 테스트를 통과했다

실제로 돌려서 확인했다.

### 1차: 1행 단독 vs 5행 함께
```
row_id         전체와함께        단독1행         차이
TEST_000001  0.4375236642  0.4375236642   0.00e+00
TEST_000017  0.3853422826  0.3853422808   1.76e-09
TEST_000213  0.4400860207  0.4400860207   0.00e+00
TEST_005332  0.4899492344  0.4899492344   0.00e+00
TEST_035185  0.5152569175  0.5152569175   0.00e+00
```
한 행에서 1.76e-09 차이가 났다.

### 대조군: 동일 입력 2회 실행
```
재실행 최대 편차  0.00e+00   (비트 단위 동일)
```
재실행은 완전히 결정적이다. 그렇다면 1.76e-09는 배치 크기 차이 때문인가, 아니면 다른 행의 **내용**이 영향을 준 것인가?

### 결정적 확인: 다른 행의 내용을 완전히 교체
대상 행은 그대로 두고 나머지 4행의 `pitcher_id`, `batter_id`, `asof_pitcher_n`, `asof_pitcher_success_rate`, `inning`, `balls_before` 를 전혀 다른 값으로 바꿨다.

```
대상 행 TEST_000017 의 예측값
  원본 5행           0.385342282568   차이 0.00e+00
  나머지4행 값 교체    0.385342282568   차이 0.00e+00
  대상행 4벌 복제      0.385342282568   차이 0.00e+00
```

**비트 단위로 동일하다.** 다른 행의 내용은 예측에 전혀 영향을 주지 않는다.
1.76e-09는 배치 크기(1행 vs 5행)에 따른 부동소수점 연산 순서 차이일 뿐, 정보 흐름이 아니다.

### 정적 분석
- `featurize()` 안에 test 프레임을 대상으로 하는 `groupby` / 집계 없음
- `BatchNorm` 등 배치 간섭 레이어 없음 (모든 NN은 `eval()` 모드, Linear/Dropout/LayerNorm만 사용)
- `np.mean(ps, 0)` 은 **행별로 모델들을 평균**하는 것이지 행 간 평균이 아님

## 라벨 역산의 합법성 — 반드시 지킬 것

`asof_*` 컬럼을 차분해 복원한 투구별 라벨(`reverse`/`middle`/`ball`/`strike`/`fastball`/`breaking`/`offspeed`)은

- ✅ **학습 시 보조 타깃으로 사용** — 합법
- ❌ **추론 시 입력 피처로 사용** — 절대 금지

### 왜 학습 타깃으로는 합법인가
`control_success` 자체가 투구 후 확정되는 정보인데 타깃으로 쓴다. 같은 논리다. 역산은 **`train.csv` 안에서만** 이루어지며, 규칙이 금지하는 것은 `test.csv` **행간** 참조다.

### 왜 추론 입력으로는 불법인가
두 가지 이유로 모두 막힌다.
1. 규칙이 "현재 투구의 실제 구종·판정·결과"를 명시적으로 금지한다
2. 애초에 불가능하다 — 테스트 행의 라벨을 역산하려면 같은 투수의 **다음 test 행**을 봐야 하는데, 그게 바로 금지된 행간 참조다

### 현재 구현
성분 모델(`cmp_*`) 4개는 **합법 피처만 입력받아 성분 확률을 예측**하고, 그 예측 확률이 y 모델의 피처가 된다. 실제 라벨은 추론 경로에 존재하지 않는다.

## 드리프트 보정 상수에 대하여

최종 예측에 상수 로짓 시프트(`−0.020`)를 적용한다. 이것이 "평가 데이터 전체를 보고 만든 사후 보정값"에 해당하는지 검토가 필요하다.

**우리 입장**
- 코드는 `test.csv` 의 어떤 집계도 참조하지 않는다. **행 독립성 테스트를 정확히 통과한다** (1행만 있어도 전체가 있어도 같은 값)
- 이 상수는 **학습 데이터만으로 도출 가능**하다: 리그 제구율 2019 .5495 → 2024 .4897 (연평균 −0.0120)과 백테스트에서 측정한 모델의 자체 하락폭(약 0.006)으로부터 기대 편향 +0.006~0.009 → `d = −0.024 ~ −0.037` 이 나온다. 실제 채택값 −0.020은 그보다 보수적이다
- 다만 **구체적 값의 최종 선택은 LB 피드백을 참고했다.** 공개 리더보드가 있는 대회에서 하이퍼파라미터를 LB로 고르는 것은 통상적 관행이지만, 판단은 팀에서 할 문제다

**보수적으로 가려면** `d=0` 으로 두면 된다. 비용은 약 **−7점**이다 (제출 3회로 실측: d=0에서 1055.1587, d=−0.020에서 1061.9107).
