# 실험 원장

팀원별 실험 결과가 `ledger_<이름>.csv` 로 쌓인다. **Drive 공유 대신 git 으로 모은다.**

- 파일명이 사람마다 달라 **충돌이 나지 않는다**
- 누가 언제 무엇을 돌렸는지 **이력이 남는다**
- Drive 폴더를 서로 공유할 필요가 없다

코랩 러너가 실험을 마치면 자동으로 여기에 커밋·푸시한다.
집계는 `colab/04_summary.ipynb` 가 이 폴더를 읽어서 한다.

## 컬럼

| 컬럼 | 뜻 |
|---|---|
| `runner` | 실행자 |
| `name` | 아이디어 이름 |
| `params_json` | 실제 설정 |
| `m24` / `m23` | 폴드2024 / 폴드2023 점수 |
| `delta24` / `delta23` | 기준선 대비 효과 |
| `se24` / `se23` | 표준오차 (2배가 유의성 문턱) |
| `verdict` | 채택후보 / 보류 / 노이즈 / 기각 |
| `lb_lo` / `lb_hi` | 관측 전이율(0.06~0.5배) 적용한 LB 기대 범위 |
